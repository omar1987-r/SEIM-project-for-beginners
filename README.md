# 🔐 Splunk SIEM Lab — Attack Detection & Log Analysis

## 📌 Project Overview

This project is a small Security Information and Event Management (SIEM) laboratory built to understand how security events generated during offensive security activities can be collected, monitored, detected, and investigated using **Splunk**.

The lab simulates a basic attacker-and-target environment where security activities such as network reconnaissance and exploitation generate events that can be investigated through a SIEM.

The main goal was to move beyond simply performing attacks and understand the **defensive side of cybersecurity**:

> **Attack → Log Generation → Log Collection → SIEM → Detection → Investigation**

---

## 🎯 Objectives

The project was designed to:

- Understand the role of a SIEM in cybersecurity.
- Generate security events from a controlled lab environment.
- Perform network reconnaissance using Nmap.
- Generate activity against a vulnerable Linux target.
- Observe the logs generated by the target system.
- Forward relevant logs to Splunk.
- Search and analyze events using Splunk.
- Understand how reconnaissance and exploitation can become visible to defenders.
- Develop basic security monitoring and investigation skills.
